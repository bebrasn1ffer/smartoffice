# practice4: среда эмуляции датчиков и проверки Docker

Каталог содержит материалы работ №3 и №4.

| Файл | Что это |
|------|---------|
| `nginx-compose.yml` | учебный compose-файл с тестовым Nginx (порт 8080), работа №3 |
| `receiver-log.txt` | журнал приёмника CTRL-01 с принятыми показаниями (работа №4) |
| `ctrl-containers.txt` | список контейнеров CTRL-01, снятый через docker compose (работа №4) |
| `scp-test.txt` | протокол передачи файла с IOT-01 на CTRL-01 по SCP (работа №3) |
| `nginx-check.txt` | протокол проверки Nginx: docker run, docker compose, HTTP-код с CTRL-01 и IOT-01 |
| `connectivity.txt` | протокол проверки связности WIN-01, IOT-01 и серверных ВМ (работа №2) |

Порт 8080 после испытания Nginx освобождён и используется приёмником показаний CTRL-01.
